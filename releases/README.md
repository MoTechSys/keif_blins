# إصدارات كيف الضيافة v2.1.0

كل مجلد يحوي تطبيقًا مستقلًا جاهزًا للتشغيل (بدون ملفات تطوير):

| المجلد | لمن؟ | الحجم |
|---|---|---|
| `android-arm64/` | الهواتف الحديثة (2016 فما بعد — الغالبية) | ~10 MB |
| `android-armv7/` | الهواتف القديمة 32-بت | ~10 MB |
| `web/` | نسخة الويب — ترفع على أي استضافة ثابتة (Netlify / Cloudflare Pages / GitHub Pages) | ~33 MB |

**لا تعرف نوع هاتفك؟** جرّب `android-arm64` أولًا؛ لو لم يُثبَّت استخدم `android-armv7`.

## الجديد في 2.1.0

- **قفل التطبيق برمز سري** (4–6 أرقام) من الإعدادات ← الحماية. يُطلب عند التشغيل وبعد 30 ثانية من ترك التطبيق. الرمز مخزَّن مشفَّرًا (SHA-256 + Salt) في مخزن منفصل — لا يتأثر بـ "مسح جميع البيانات".
- **مجلد على الهاتف** `Documents/كيف الضيافة/` يحوي مجلدات مرتّبة بالنوع ثم السنة:
  `الفواتير/` · `عروض الأسعار/` · `كشوف الحساب/` · `سندات القبض/` · `النسخ الاحتياطية/`
- **حفظ تلقائي للـ PDF** في مجلده عند أي معاينة أو مشاركة، مع زر "فتح الملف المحفوظ".
- **نسخة احتياطية تلقائية** (JSON) بعد كل تعديل في `النسخ الاحتياطية/` (تُحفظ آخر 14 نسخة) + حفظ يدوي + استرجاع من القائمة.
- شاشة **الملفات المحفوظة** (الإعدادات ← مجلد الهاتف): تصفّح/فتح/مشاركة/حذف/استرجاع.
- المشاركة ترسل **الملف نفسه المحفوظ في المجلد** (واتساب، البريد، Drive…).
- تحصينات: الترقيم لا ينهار على أرقام غير صالحة، الاسترجاع يتجاوز السجلات التالفة بدل الفشل، نسخة أمان تلقائية قبل المسح.

> نسخة الويب: قاعدة البيانات محلية في المتصفح؛ حفظ المجلدات على الهاتف متاح في تطبيق أندرويد فقط (على الويب تُستخدم المشاركة/التنزيل).
