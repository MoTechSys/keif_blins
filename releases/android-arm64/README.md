# كيف الضيافة — أندرويد (هواتف حديثة / arm64)

1. انقل ملف `keif-aldiafa-v2.0.0-arm64.apk` إلى الهاتف (واتساب / بريد / كابل).
2. افتحه من مدير الملفات واسمح بـ "التثبيت من مصادر غير معروفة" إن طُلب.
3. اضغط تثبيت، ثم افتح التطبيق واتبع خطوات البداية الثلاث على الشاشة الرئيسية.

بياناتك تُحفظ على الهاتف فقط — احفظ نسخة احتياطية من الإعدادات بشكل دوري.
