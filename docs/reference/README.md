# النماذج المرجعية المعتمدة من المستخدم

صور مصغّرة (JPEG) للملفات التي أرسلها المستخدم كمرجع للتصميم. الأصول (PDF/ZIP) ليست في المستودع لحجمها؛ الصور كافية للمقارنة البصرية.

| الملف | ما هو | كيف استُخدم |
|---|---|---|
| `ref_invoice_official.jpg` | فاتورة «كيف الضيافة» الرسمية (من نظامه القديم) | **المرجع الأساسي** للثيم الرسمي: ترويسة (شعار، المملكة، اسم المؤسسة، س-ت)، شارة نوع المستند، بيانات العميل/الفعالية، جدول (الوصف \| عدد الأيام \| السعر \| الإجمالي) بوصف متعدد الأسطر، الإجماليات يسارًا، تذييل بنكي + ختم. طلب المستخدم إضافة عمود «م» وحدودًا أوضح وإظهار الضريبة/الخصم فقط عند وجودهما. |
| `ref_statement_official.jpg` | كشف حساب من نظامه القديم (أغسطس 2026) | مرجع الهوية فقط؛ **رُفض** منطقه (إجمالي فواتير فترة) واعتُمد الدفتر الكلاسيكي مدين/دائن/رصيد بنفس الهوية. |
| `ref_receipt_halfpage.jpg` | حزمة سند القبض (`keif-aldiafa-receipt-voucher-package.zip`) | مرجع سند القبض نصف الصفحة: حقول منقّطة، خانات طريقة الدفع، مبلغ في إطار، توقيعات. |
| `ref_delivery_note_royal.jpg` | مذكرة استلام بالثيم «الملكي» (كحلي/ذهبي) من حزمة `keif-aldiafa-delivery-note-system.zip` | الثيم الملكي القديم — **استُبدل** بالثيم الرسمي البسيط بطلب المستخدم («غيّر»). يبقى في `lib/pdf/pdf_theme.dart` مرجعًا غير مستخدم. |

المعاينات الحالية لمخرجات التطبيق في `../renders/`.
